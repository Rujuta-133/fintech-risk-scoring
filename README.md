## Business Problem

Loan and BNPL providers need to make fast and accurate decisions when users apply for credit. The goal of this system is to predict the repayment risk of a loan application in order to decide whether it should be approved instantly, sent for manual review, or rejected.

This is a challenging problem because repayment outcomes are only known weeks or months after approval, which exposes lenders to financial loss if high-risk customers are approved. Additionally, the available data is often incomplete, noisy, and fragmented across sources, making reliable risk assessment difficult.
